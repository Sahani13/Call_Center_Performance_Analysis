Call Center Performance Analysis: Simulation with Limited Agents

Overview
This repository contains a discrete event simulation model of a call center system with limited agents. The simulation models call arrivals, service times, agent resource allocation, and queuing behavior to analyze key performance metrics such as average wait time, throughput, queue length, and agent utilization.

Features
Parameterized simulation- Allows variation of agents, call arrival rates, and service rates.
Performance metric tracking- Evaluates the system under different configurations to identify bottlenecks.
Automated Data Export- Experiment scripts run multiple scenarios and save both summary results and raw call level data to CSV files.
Data Visualization- Automatically generates PNG graphs illustrating capacity, traffic bottlenecks, agent efficiency, and wait time distributions.
